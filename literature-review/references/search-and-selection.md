# Search and Selection

A literature search should be broad enough to reduce obvious blind spots and documented well enough that another researcher can understand how the corpus was assembled.

## Record the search process

Keep a search log containing:

- database or source,
- query terms,
- filters,
- date searched,
- time span covered,
- number of records retrieved,
- changes made after exploratory searches.

For formal reviews, preserve exact queries whenever possible.

## Search iteratively

One query rarely captures a field's vocabulary. Use multiple forms of discovery:

- synonyms and alternative terminology,
- broader and narrower keywords,
- several databases or indexes,
- backward reference chasing,
- forward citation chasing,
- key-author searches,
- recent reviews as maps rather than substitutes for primary studies.

Re-search near the end of the project so that the review is not obsolete before completion.

## Separate discovery from eligibility

Search broadly, then apply explicit selection criteria. Do not quietly exclude studies because their results are inconvenient or because they complicate the narrative.

When exclusions require judgment, record the reason.

## Use older work when it remains scientifically relevant

Recency is not a quality metric. New papers may provide the latest evidence, but older work can contain foundational methods, prior negative results, or questions that have been repeatedly rediscovered.

A claimed "gap" is weak if it exists only because older literature was not examined.

## Detect saturation carefully

A search is not complete merely because recent papers repeat familiar citations. Signs that more searching is needed include:

- important concepts use multiple terminologies,
- key claims trace back to papers not yet read,
- studies cite separate communities that rarely cite each other,
- a conclusion rests heavily on one review article,
- disagreements may be explained by evidence outside the current database or discipline.
