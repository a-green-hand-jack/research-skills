# Research Software

Treat research software as part of the scientific method when results depend on it.

## Core behavior

- Make behavior explicit and testable.
- Track changes with version control.
- Document intent, interfaces, examples, and citation.
- Expose configuration rather than hiding it in local state.
- Make tools composable for automated workflows where practical.
- Archive stable versions used in publications.
